# Бурмалграм

Готовый минималистичный веб-мессенджер на Firebase Authentication + Realtime Database.

## Что работает

- пошаговая регистрация: email/пароль → имя и уникальный username → дата рождения → необязательное описание;
- письмо подтверждения email отправляется сразу после создания аккаунта; на экране подтверждения есть напоминание проверить «Спам», «Промоакции» и «Корзину»;
- вход, выход и восстановление пароля;
- профиль и настройки имени, username и описания;
- server-side защита уникальности username через RTDB transaction;
- поиск пользователей по username (в том числе по началу username);
- заявки в друзья, принятие/отклонение, автоматическое создание личного чата после принятия;
- личные realtime-чаты;
- создание групп и каналов;
- при создании/редактировании можно добавлять только друзей;
- владелец группы/канала может менять название, описание и участников;
- в группе писать могут участники, в канале — только создатель;
- настройки темы и компактного режима;
- звонки и отправка фото/файлов намеренно не реализованы.

## Firebase: один раз перед запуском

1. Firebase Console → Authentication → Sign-in method → включите **Email/Password**.
2. Убедитесь, что создана Realtime Database.
3. Обязательно примените **новые** Security Rules из `database.rules.json`. Именно эти правила исправляют добавление в друзья, приватные чаты и настройку участников групп/каналов.
4. Firebase Console → Authentication → Settings → Authorized domains: добавьте домен сайта (для Firebase Hosting — домен Hosting; для GitHub Pages — домен Pages).

## Запуск

### Вариант 1 — Firebase Hosting

Готовая папка для Hosting находится в `dist`.

```bash
firebase deploy --only hosting,database
```

`firebase.json` уже указывает Hosting на `dist`.

### Вариант 2 — GitHub Pages / другой static hosting

Можно опубликовать содержимое репозитория как статический сайт. Firebase Authentication и Realtime Database продолжат работать, но Security Rules всё равно должны быть применены в Firebase Console.

### Локальная разработка

```bash
npm install
npm run dev
```

Для самого простого просмотра `index.html` можно открыть его напрямую: используемые Firebase compat-скрипты подключены обычными `<script>` из официального CDN.

## Конфигурация

Firebase Web Config уже вставлен в `src/main.js` и `dist/src/main.js` и совпадает с конфигурацией проекта, предоставленной для Бурмалграма.

## Важно

Web API key из Firebase config не является секретом. За доступ к данным отвечают Firebase Authentication и Realtime Database Security Rules. Перед публичным релизом протестируйте регистрацию, две тестовые учётные записи, добавление в друзья, создание группы/канала и удаление участника.
